# Watch Roulette PWA v3.0

UI overhaul based on v2.5. Data storage remains compatible with `watch-roulette-data-v2`.

## New in v3.0
- Light / dark / system theme.
- Bottom navigation: Ruleta, Colección, Ajustes.
- Visual collection with photos.
- Search and category filter.
- Improved roulette screen and animation.
- Optional weighted selection favoring less-used watches.
- Existing watch data is preserved and missing seed watches are added without overwriting user data.

Upload the contents of this folder to the root of the GitHub Pages repository.
